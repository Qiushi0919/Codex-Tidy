# Changelog

All notable changes are documented here.

## [0.1.0-beta.1] - 2026-08-29

### Added

- Native macOS thread and workspace browser backed by local Codex App Server.
- Disk-usage overview for Codex sessions, archived sessions, worktrees, caches, and app support data.
- Conservative artifact scanner with Trash-based cleanup for allowlisted rebuildable caches.
- App Server-based thread archive and permanent deletion with recent-thread protection.
- Read-only JSON CLI for listing threads, inspecting storage, and scanning workspaces.
- Universal Apple Silicon and Intel build, custom app icon, privacy documentation, and public-release metadata.
